Fundamentos

Glossário de domínio

Conceitos centrais das funcionalidades disponíveis.

Agente
Entidade de IA configurável (LLM + personalidade + conhecimento), pessoal ou compartilhada.
Integral Memory / Life Memory
Memória persistente do agente/usuário — conhecimento e contexto estável carregado entre conversas.
On-Demand Knowledge
Conhecimento dinâmico buscado em tempo real via integrações e fontes de dados.
RAG
Base de conhecimento (texto, arquivos, áudio/vídeo transcrito) indexada para busca semântica.
Skill
Habilidade modular atribuível a um agente sem deploy (prompt, tool ou composite) — amplia o que o agente sabe fazer.
MCP
Model Context Protocol — protocolo para expor ferramentas/contexto a agentes.
Multi-tenant / RBAC
Isolamento por workspace e autorização por papel (role-based).
Crédito / quota
Unidade de consumo por plano (armazenamento, agentes, mensagens/tokens).
Comitê
Conversa com vários agentes (N agentes) na mesma sessão.
